💡 行前關鍵準備

  1. 準備好實體護照：不論是走窗口還是用機器，每位要換票的人都必須持有「印有短期滯在貼紙」的實體護照原件（不可用照片或影本）。

  2. 準備好憑證（QR Code）：在 Klook、KKday 等平台購買後收到的電子憑證 QR Code 要先儲存在手機裡。

🚄 快速通關步驟：使用「綠色自動售票機」

關西機場第一航廈二樓的 JR 站閘門旁，有一排綠色自動售票機（部分機台上方會標示可讀取護照）。用機器換票通常比在窗口排隊快上數倍！

【第一階段：兌換 JR PASS 實體票】

  1. 機台畫面右上角切換語言為 「繁體中文」。

  2. 點選 「停靠站找尋/交換（E-Ticket Exchange Order）」。

  3. 依照畫面指示，掃描您手機上的 JR PASS QR Code。

  4. 輸入您當時登記的護照號碼。

  5. 畫面跳出個人資料與使用條款，確認無誤後點選確認。

  6. 將護照正本翻到照片頁，放入機台的護照讀取窗口進行掃描。

  7. 機器就會吐出您的 JR PASS 實體磁氣票卡（請妥善保管，進出閘門要塞這張）。

【第二階段：直接在機台劃位 HARUKA 指定席】

換好實體 PASS 後，不用拔卡離開，直接在同一台機器繼續操作劃位：

  1. 在繁體中文主畫面點選 「使用現有車票預約指定席（回數票預約指定席）」。

  2. 將剛剛吐出來的 JR PASS 實體車票插入機台（一次最多可插入 4 張同行者的 PASS 一起劃位）。

  3. 選擇出發站（關西機場）與目的地（天王寺/京都...等）。

  4. 選擇您想搭乘的 HARUKA 班次與時間。

  5. 在座位表上自行挑選車廂與座位。

  6. 確認後，機器會吐回您的 JR PASS，並多吐出一張 「HARUKA 指定席座位券」。

為了讓您在排隊的狂熱中適度「減壓」，建議將行程分為三階段：
